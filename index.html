Royaume médiéval RPG

À faire une seule fois, dans l'ordre. Après ça, le jeu se met à jour tout seul à chaque lancement : tu n'auras plus rien à réinstaller.

1Installer Prism Launcher

  1. Va sur prismlauncher.org/download et télécharge la version pour ton ordinateur.
  2. Installe-le et ouvre-le.
  3. En haut à droite, clique sur ton nom (ou Comptes) puis Configurer les comptes → Ajouter un compte Microsoft et connecte-toi avec le compte qui possède Minecraft Java.

2Créer l'instance avec l'installeur

Télécharger l'installeur
  1. Dans Prism, clique sur Ajouter une instance (en haut à gauche).
  2. Dans la colonne de gauche de la fenêtre, clique sur Importer.
  3. Clique sur Parcourir et choisis le fichier Royaume-installeur.mrpack (il est dans ton dossier Téléchargements).
  4. Clique sur OK. Une instance appelée Royaume-installeur apparaît dans la liste. Elle est vide pour l'instant, c'est normal.

3Coller la ligne de mise à jour

C'est l'étape qui permet que le jeu se mette à jour tout seul.

  1. Fais un clic droit sur l'instance Royaume-installeur, puis clique sur Modifier.
  2. Dans la colonne de gauche, clique sur Paramètres.
  3. En haut de la fenêtre, clique sur l'onglet Commandes personnalisées.
  4. Coche la case Remplacer les paramètres globaux.
  5. Clique dans le champ Commande de pré-lancement et colle cette ligne (avec les guillemets) : "$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://ml123455.github.io/royaume-medieval-pack/pack.toml
  6. Laisse les autres champs vides.

4Régler la mémoire

  1. Dans la même fenêtre, clique sur l'onglet Java.
  2. Coche la case pour personnaliser la mémoire (« Mémoire »).
  3. Mets la mémoire maximale à 5120 Mo. Si ton ordinateur a seulement 8 Go de RAM, mets 4096 Mo.
  4. Ferme la fenêtre : tout s'enregistre tout seul.

5Lancer le jeu

  1. Sélectionne l'instance Royaume-installeur et clique sur Lancer.
  2. Une petite fenêtre s'ouvre et télécharge les mods (environ 360 Mo). Ça peut prendre quelques minutes la première fois. Ne la ferme pas : elle se ferme toute seule quand elle a fini.
  3. Minecraft démarre ensuite tout seul. Le chargement du jeu avec tous les mods prend 2 à 3 minutes.

6Activer la traduction française (une fois)

Les objets et les sorts de nécromancie (Goety) sont traduits en français. Il faut l'activer une seule fois.

  1. Dans Minecraft : Options → Langue → choisis Français (France), puis Terminé.
  2. Options → Packs de ressources. Dans la colonne de gauche, repère Goety-FR et clique sur la flèche pour le passer dans la colonne de droite. Clique sur Terminé.

7Entrer dans le serveur

  1. Dans Minecraft, clique sur Multijoueur puis Ajouter un serveur.
  2. Dans « Adresse du serveur », écris l'adresse que Marius t'a donnée en privé. Le nom, tu mets ce que tu veux.
  3. Double-clique sur le serveur pour te connecter.
Ensuite, à chaque fois : tu cliques juste sur Lancer. Si Marius a ajouté des mods, ils se téléchargent tout seuls avant que le jeu démarre.

Ça ne marche pas ? Vérifie que la case « Remplacer les paramètres globaux » est bien cochée (étape 3) et que la ligne est collée en entier, avec les guillemets. Sinon, envoie une capture d'écran de l'erreur à Marius.

Pour alléger le jeu : Options → Vidéo → Particules : Minimal, Météo : Rapide, Nuages : Désactivés, distance d'affichage entre 8 et 10.
