Royaume médiéval RPG

Installation à faire une seule fois. Ensuite, le jeu se met à jour tout seul à chaque lancement.

  1. Installer Prism Launcher

    Télécharge-le sur prismlauncher.org, puis ajoute ton compte Microsoft (celui qui possède Minecraft Java).

  2. Importer l'installeur Télécharger l'installeur

    Dans Prism : Ajouter une instance → Importer → choisis le fichier téléchargé. Une instance vide se crée, avec NeoForge.

  3. Coller la ligne de mise à jour

    Clic droit sur l'instance → Modifier → Paramètres → Commandes personnalisées. Coche la case, puis colle cette ligne dans Commande de pré-lancement :

    "$INST_JAVA" -jar packwiz-installer-bootstrap.jar https://ml123455.github.io/royaume-medieval-pack/pack.toml
  4. Régler la mémoire

    Même fenêtre, section Java : mets la mémoire maximale à 5120 Mo (ou 4096 si ton PC a 8 Go de RAM).

  5. Lancer le jeu

    Le premier lancement télécharge les mods (environ 270 Mo), c'est un peu long. Si une petite fenêtre s'ouvre, laisse-la finir. Ensuite, chaque lancement vérifie les nouveautés tout seul.

Pour alléger le jeu : Options → Vidéo → Particules : Minimal, Météo : Rapide, Nuages : Désactivés, distance d'affichage entre 8 et 10.

L'adresse du serveur t'est donnée en privé, elle n'est pas écrite ici.
